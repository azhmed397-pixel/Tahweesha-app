# تحويشة 💰 — تطبيق ادخار أوفلاين

تطبيق لتنظيم المصاريف والتحويش. بيشتغل من غير نت بعد أول فتحة، وبيتسطّب على الموبايل زي أي تطبيق (PWA).

## المميزات
- مصاريف ودخل، وتقدر تعدّل أو تمسح وتتراجع، مع بحث وفلاتر
- محافظ متعددة وتحويل بينها
- أهداف ادخار وميزانية لكل فئة مع اقتراح تلقائي
- ديون وسلف (ليا / عليا)
- اشتراكات ومصاريف متكررة بتتسجل لوحدها
- قائمة أمنيات بقاعدة الانتظار (يومين أو 30 يوم)
- متابعة الجمعيات
- تحديات: 52 أسبوع، أيام من غير صرف، وسلسلة التسجيل
- 15 وسام
- 7 حاسبات: الهدف، الشهادات، الأقساط، تقسيم الفاتورة، صندوق الطوارئ، وغيرها
- تقارير ورسوم بيانية، مقارنة بالشهر اللي فات، ونصايح ذكية
- وضع ليلي، قفل برقم سري، تصدير CSV، ونسخة احتياطية JSON

## الخصوصية
كل البيانات بتتحفظ على جهازك بس. خد نسخة احتياطية كل فترة من «الإعدادات».
الرقم السري قفل للخصوصية، مش تشفير للبيانات.
